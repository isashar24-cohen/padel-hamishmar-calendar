# Padel Hamishmar calendars

Subscription calendars (iCalendar) for the Mishmar padel teams in the Hapoel Tel Aviv workplace league, season 2026/27.
They hold only the public league schedule (dates, times, courts, team names), generated from the league site.

| Calendar | File |
|---|---|
| Mishmar 1 | `mishmar-1.ics` |
| Mishmar 2 | `mishmar-2.ics` |
| Mishmar 3 | `mishmar-3.ics` |
| Mishmar 4 | `mishmar-4.ics` |
| Mishmar 5 | `mishmar-5.ics` |
| Mishmar 6 | `mishmar-6.ics` |
| All Mishmar teams | `mishmar-all.ics` |

Subscribe with the raw URL, e.g. `https://raw.githubusercontent.com/isashar24-cohen/padel-hamishmar-calendar/main/mishmar-1.ics`.
The files are updated automatically when the league changes the schedule; do not edit them by hand.

Calendar files are regenerated at 07:52 and 22:52 Israel time, about ten minutes after the league schedule is synced.
